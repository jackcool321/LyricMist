<h1 align="center">LyricMist</h1>

<p align="center">在桌面和菜单栏，跟上每一句歌词。</p>

<p align="center">macOS 13.0+ · Spotify · Apple Music</p>

---

LyricMist 是一款 macOS 歌词小工具。照常在 Spotify 或 Apple Music 中播放音乐，歌词会自动出现在桌面或菜单栏，无需来回切换播放器。

## 功能

- **桌面歌词** — 悬浮显示当前歌词，自由拖动位置，调整字体、颜色和宽度。
- **菜单栏歌词** — 将歌词收进菜单栏，长句自动滚动。
- **自动同步** — 自动查找在线歌词，随歌曲进度切换，切歌后自动更新。
- **随手控制** — 悬停桌面歌词即可播放、暂停或切换歌曲。

应用同时提供 Dock 图标和菜单栏入口，点击 Dock 图标可打开设置；歌词位置和样式会在下次打开时保留。

## 开始使用

1. 打开 LyricMist，并在 Spotify 或 Apple Music 桌面客户端中播放歌曲。
2. 首次使用时，按提示授予自动化权限，允许 LyricMist 访问播放器。
3. 歌词会自动显示。拖动可调整桌面歌词的位置，点击菜单栏图标可打开设置。

在「设置 → 歌词展示」中，可切换桌面与菜单栏两种展示方式。

## 常见问题

**为什么有些歌曲没有歌词？**

歌词来自 LRCLIB 和网易云音乐，需要联网获取。部分歌曲可能没有匹配的同步歌词，此时会显示歌名和歌手。

**已经播放音乐，但应用没有识别到？**

请确认使用的是桌面客户端，并在「系统设置 → 隐私与安全性 → 自动化」中允许 LyricMist 控制对应播放器，然后重新打开应用。

**在哪里修改歌词样式？**

点击菜单栏图标进入设置，可调整桌面歌词的字体、字号、颜色和宽度。菜单栏歌词使用系统字号与颜色，可单独调整展示宽度。
